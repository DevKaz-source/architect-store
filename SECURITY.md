# Security Policy

Architect Store handles payment state, wallet entries and encrypted digital deliveries.
Security reports should therefore be handled privately.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting feature for this repository and include:

- the affected component and version;
- clear reproduction steps;
- the potential impact;
- a suggested mitigation, when available.

Never include live tokens, credentials, customer data or redeemable stock in a report.

## Supported version

The latest version on the `main` branch receives security fixes. This repository remains
a sandbox/portfolio project until the production-readiness checklist is completed.

For implementation details and the production checklist, see
[`docs/SECURITY.md`](docs/SECURITY.md).
